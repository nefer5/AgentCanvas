# 绘图默认值与局部擦除

默认参数只用于新建元素，不修改已保存的画布对象。每次打开或切换项目恢复这些默认值；同一次打开期间，各绘图工具分别记住手动调整的样式。

| 工具 | 默认值 |
| --- | --- |
| 文字 | 黑色 `#1e1e1e`、Normal / Nunito、小号 16、居中、100% 不透明 |
| 几何形状 | 黑色、透明背景、第二档线宽 2、实线、朴素（roughness 0）、尖锐边角、100% 不透明 |
| 自由书写 | 第一档线宽 1 |
| 箭头 | 黑色、第二档线宽 2、实线、朴素、曲线类型、起点无箭头、终点实心三角、100% 不透明 |

## 局部橡皮擦

在顶部工具栏原橡皮右侧点击“局部橡皮擦”，选择小/中/大直径，按住鼠标或触笔拖动。直径按屏幕像素固定，缩放后仍与光标圆圈对应。点击其他工具、按 Esc 或再次点击按钮退出，Ctrl+Z 撤销一次拖擦，Ctrl+Shift+Z 重做。

当前支持自由书写笔迹；不擦除锁定笔迹、文字、图片或几何图形。顶部原有橡皮仍用于整对象删除。切开的笔迹保留颜色、压感数据和编辑能力，使用标准 Excalidraw 元素保存；笔迹端部会重新计算平滑和模拟压感，因此端部外观可能有轻微变化。

## 坐标系素材

素材库新增平面直角坐标系，包括 x/y 轴、箭头与原点 O。插入后默认成组，可取消组合分别编辑。旧素材库首次升级时补入坐标系，保留自定义素材；用户随后主动删除坐标系时，不会在刷新后重新添加。

## 验证

使用隔离数据目录和浏览器会话验证，未操作用户项目画布或领取 Agent inbox。测试覆盖线段与圆的交点、笔迹旋转、压感插值、锁定对象、样式隔离和素材库升级。浏览器实测默认参数、局部擦除、单步撤销/重做和刷新恢复。

局部橡皮擦使用 Excalidraw 自定义工具状态，入口通过 React portal 插入原橡皮右侧；尺寸设置出现在按钮下方。工具栏挂载适配集中在 `PartialEraser.tsx`，升级 Excalidraw 时需复核 `toolbar-eraser` 锚点和窄屏布局。
