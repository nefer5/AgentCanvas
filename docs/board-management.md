# 画板状态、历史与空间管理设计

日期：2026-09-26。状态：核心功能已于0.2.0实施，运行方式与限制见[使用与恢复说明](reliability-guide.md)。本文仍包含后续目标，不能将所有设计条目当作已实现。方案依赖稳定 boardId、聊天绑定与持久接收协议。本文不执行任何历史数据清理。

## 界面结构

绘图区保持主体，右侧协作栏提供三个区域：发送、连接与可靠性、画板历史。连接与可靠性可折叠；历史列表通过按钮打开侧栏或抽屉，不常驻占用绘图区。窄窗口改用抽屉。

顶部常驻一行摘要：画板名称 / 所属项目 / 绑定工具与聊天 / 保存状态，以及“历史”入口。聊天标题可能重名，因此展开后可核对短身份标识；完整路径与技术ID放详情，不要求用户理解协议字段。

“连接与可靠性”默认折叠，标题包含状态摘要及异常数量。折叠时仍保留会影响数据保存或发送的警示与直接操作；新异常给一次非打断提示，不反复强制展开，不把恢复/重连做成模态弹窗循环。

示意文案：

```text
光路草图 · 项目 A                       [画板历史]
绑定：Codex / 光学结构讨论              已保存 20:32

给 Agent 的说明……
[发送给 Codex / 光学结构讨论]

▸ 连接与可靠性                  1 项需要处理
  Agent 暂时离线，发送将保留给原聊天

展开后：
  本地服务     正常 · 2 秒前确认
  当前聊天     离线 · 目标保持不变
  画板保存     本机已保存 · 20:32
  本地草稿     已保存
  待处理       2 条等待接收 · 1 条处理中
  编辑窗口     另有 1 个窗口打开本画板
  [重新检查] [重连当前聊天] [保存副本]
  ▸ 诊断详情
```

以上为示意，不是当前运行界面或实时状态。

## 连接与可靠性

| 检查项 | 显示内容 | 允许的操作 |
|---|---|---|
| 本地服务 | 正常、检查中、暂时不可达、协议不兼容；最后成功时间 | 重新检查、复制诊断摘要、打开启动指引 |
| 聊天绑定 | 原工具/聊天、匹配或失效 | 查看绑定；明确操作后转交/重新绑定，绝不自动换目标 |
| 接收通道 | 等待接收、处理中、离线、需手动领取 | 重连当前目标、查看待处理条目 |
| 画板保存 | 服务端已确认保存、尚未保存、失败、冲突 | 保存副本、重试、打开冲突恢复 |
| 浏览器草稿 | 已写入、失败、空间不足 | 导出副本；不能把写入失败当持久化成功 |
| 其他窗口 | 当前画板的活跃窗口数、最近活动时间 | 定位窗口（适配器支持时）、查看版本差异 |
| 存储空间 | 当前画板/项目占用、可清理估算 | 打开空间管理 |

状态分别计算，不使用一个“连接正常”覆盖全部层面。处理中的接收者不应因 wait 已交付就被描述为整体失联。“传输已交付”也不能写成“模型已开始处理”，必须由宿主或处理 ACK 证明。

### 后台服务是否失效

- 建议前台页约5秒一次健康探测，单次约2秒超时；一次失败显示“连接不稳定”，连续失败显示“暂时不可达”。具体阈值为初始参数，可由测试调整。
- 错误类型分开：连接拒绝、请求超时、版本不兼容、服务在线但保存失败。单次超时不能认定进程已崩溃。
- 显示最近成功时间，后台页被浏览器节流或电脑休眠后标记“状态待刷新”；回到前台立即重新探测，不沿用旧绿灯。
- 健康响应包含协议版本、服务实例 epoch；epoch 改变后重新确认绑定、版本与接收能力，再恢复写入，不能仅 HTTP 200 就继续提交。
- 服务不可达时保留当前画布；能写浏览器草稿则明确显示“仅浏览器草稿”，否则显示“尚未持久保存”并提供本地文件导出。服务不可达时不能声称已加入服务端待处理箱。
- 已加载网页无法依赖失效的同一个 HTTP 服务执行“重启自己”。第一版提供本地正式启动器/CLI恢复指引；只有独立本机助手或已注册协议适配器真正可用时，才显示可执行的恢复按钮。
- 不提供无条件全局重启。涉及其他聊天连接的操作必须列明影响；普通重连只重连当前绑定。
- 技术详情可折叠查看：最后检查时间、服务/协议版本、短板ID、请求ID和错误阶段。诊断复制不含令牌、完整画板内容或用户聊天正文，路径默认脱敏。

## 画板历史

历史单位为“画板”，每条有稳定 boardId；画板内部的自动保存版本另在详情中管理。刷新/重连/每次保存不应各生成一张历史画板。

列表默认当前项目，支持切换全部本地项目；置顶当前画板与收藏，其他按最近修改排序。支持标题搜索、项目/工具/状态筛选和分页，缩略图按需加载。名称、缩略图、最近修改时间、所属项目、绑定聊天、大小与活动状态足以完成日常选择。

状态：当前打开、其他窗口使用中、待接收、处理中、已归档、回收站。后台不可达或项目目录不在本机时，缓存信息标注“上次记录”，不能将检查失败视作空闲或可删除。

操作：打开、重命名、收藏、另存副本、导出、归档、移入回收站。打开旧画板不修改其聊天归属；新聊天接手时明确选择另存副本或转交。画板副本获得新ID，不继承待处理任务或领取凭据。

“归档”只降低日常列表干扰，不承诺释放空间。归档已结束工作的画板不会删除聊天或项目；有进行中任务时先处理任务状态，不能借归档绕过保护。

## 手动清理与长期容量

### 清理入口与预览

历史抽屉提供“管理空间”。先展示分类占用：当前画板、自动保存版本、提交快照/附件、预览缓存、回收站；当前无法扫描的项目单独说明。缩略图缓存与原始画板不能混称为“垃圾”。

预设筛选可包括：已归档且90天未修改、未绑定且长期未使用的临时画板、历史版本过多、可再生成的预览缓存。90天仅为候选筛选建议，不自动勾选删除，也不代表可丢弃。

用户勾选后展示对象数、所在项目、预计可释放空间、会保留的数据、被保护而跳过的对象。真正执行前服务端在锁内再次检查对象版本及活跃状态，不能相信过期列表中的可删除标记。

### 默认保护

- 当前画板、其他活跃窗口正在编辑的画板、待发送/待接收/处理中任务、未解决冲突恢复副本默认禁止清理。
- 收藏画板不进入批量清理候选。未保存变化、状态未知、宿主无法确认的任务同样不视为空闲。
- 用户先关闭编辑、另存草稿或显式结束任务，再清理；不能强杀其他 Agent、提前 complete 或抛弃待处理提交来满足清理条件。
- 清理范围限定为指定 boardId 的受管理数据。不得递归删除用户项目根目录、整个 .agent-canvas、其他画板或整个浏览器 origin 存储。
- 共享图片/附件需要引用计数或可追踪引用集合，最后一个引用解除后才可进入回收；展示的空间估算应扣除仍被其他画板引用的部分。

### 可恢复删除

“移入回收站”先建立回收清单，再在同卷受管理回收目录中迁移画板数据、绑定元数据与附件引用信息；部分失败可恢复/重试。通过适配器复用本机安全删除设施时，也必须能关联 boardId 和恢复位置。

回收清单记录原位置、boardId、删除时间、操作者及版本，保留恢复入口。恢复时原位置已占用或板ID冲突必须报冲突或另存新板，禁止覆盖。移入回收站并不等于磁盘空间已经释放，UI须区分两者。

第一版不自动永久删除。清空回收站是独立操作，展示数量、容量与不可恢复提示后由用户确认；不能把“清理旧画板”默认解释为立即永久销毁。当前聊天绑定的已删除板链接显示回收状态，不静默创建空板替代。

已有打开页面在删除竞争中必须被版本/生命周期校验拦截：即使窗口在线信息过期，也不能保存到已回收的板路径并把它重新创建出来。

### 限制自动保存与缓存膨胀

- 只对有内容变化的场景落盘；高频编辑合并保存，避免轮询或光标状态制造完整版本。安全持久化与供用户回看的历史版本可以采用不同频率。
- 历史保留策略按画板设置，提供预览：例如最近50个普通自动版本，并保留最近30天每日一个代表版本；这只是初始建议，尚未启用。
- 任何版本精简不得删除当前版本、具名里程碑、被提交/提案引用的版本、未解决冲突快照及受保护附件；执行前解释实际能回收多少。
- 可再生成的缩略图/预览缓存可设容量上限并自动淘汰，缺失时重建；不能自动淘汰原图附件或唯一草稿。
- 达到容量提醒阈值后提供“管理空间”，默认不自动清理用户内容。第一版做按需扫描和手动管理，无需新增常驻定时清理任务。
- 每次清理记录结果：成功、跳过、失败及真实回收字节数。事件日志自身按数量/容量轮转，避免诊断功能成为新的膨胀源。

## 独立模式与内嵌模式

独立AgentCanvas的数据由本地桥接服务管理；现有DSH内嵌模式由宿主持有画板与提交记录。UI可以共用状态表达，但历史/清理必须调用各自数据所有者的接口，不能从独立画板的 .agent-canvas 目录推断DSH历史，或越过宿主删除其聊天数据。

适配器声明 history、storageStats、trash、restore、restart 等能力。只显示真正支持的动作，缺失时解释入口；不能渲染一个永远无效的“修复”按钮。

## 实施依赖与验收

先实现 board/binding 身份和服务状态协议，再接真实UI状态；可并行准备布局，但不能用固定绿灯或模拟历史充当已完成功能。

验收至少覆盖：

1. 折叠面板仍能看见未保存/错误目标/离线警示；正常时不干扰画图，键盘和窄窗可用。
2. 服务断开、慢响应、恢复、实例重启、页面休眠分别显示真实状态；断网继续编辑后可以导出，恢复时处理版本冲突。
3. 跨项目/工具/聊天的历史正确分区；打开旧板不改绑，复制不继承任务。
4. 清理预览后另一窗口开始编辑或Agent领取任务，执行必须重新检查并跳过；删除后的旧页面不能复活原板。
5. 回收/恢复过程被中断、重试、目录迁移、板ID冲突均可恢复，其他画板字节不变。
6. 共享附件仍被引用时不能删除；版本裁剪保护具名、提交和冲突引用。
7. 大量历史分页与按需缩略图保持可用，统计标明范围/时间，回收站容量不冒充已释放空间。
8. 现有安装/升级保留画板、绑定与回收清单；用户数据和诊断原文不进入发布包或源码上传。
